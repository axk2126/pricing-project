# pricing-project

Individual pricing project in Price Management, ZSEM MBA 2026/27 (case 05, Novčić Pay).
The company shown on the site is fictitious; this is a student project.

| | |
|---|---|
| Company website with the pricing section | https://axk2126.github.io/pricing-project/ |
| Pricing analysis (nine pages) | https://axk2126.github.io/pricing-project/dashboard/ |
| Calculation workbook, live formulas | [`dashboard/Novcic-Pay-pricing-calculations.xlsx`](dashboard/Novcic-Pay-pricing-calculations.xlsx) |

`index.html` is the website (one file, no external resources). `dashboard/` holds the analysis behind the
price list: customers and value, pricing strategy, the numbers, price presentation, risk and scenarios,
benchmark, KPIs and method. Every figure there is produced in the workbook and was recomputed
independently in Python; the two agree to the cent.
